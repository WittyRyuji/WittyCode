# 缓存优先的 Harness 修复与独立复审（2026-11-13）

## 结论与边界

已把前两份报告中可独立离线验证的缓存和运行时缺陷落实到代码：核心修复提交为 `854138e`，适配器 EOF／损坏帧补丁为 `2b6eeae`。原报告是当日诊断，不再代表当前实现；各项结果以下表为准。

**修复的是导致重算、错误重放、错误统计和不可靠恢复的客户端行为，不是给出服务端命中率承诺。** 正常同配置续步原来就保持前缀；本轮重点消除回合间配置变化引起的不必要改写。真实模型调用 **0 次**，没有读取或修改用户的真实设置、账号和会话。GPT 与 Devin Opus 的实际缓存差距仍未归因、未做同模型 A/B。

## 缓存修复

| 项目 | 已实施 | 离线验收 |
| --- | --- | --- |
| 指令前缀 | 首轮完整指令存进会话；日期、Plan／Auto、权限、项目规则、技能、思考语言和服务器说明变化时，在新用户消息之前追加 developer 更新，不改旧指令；更新声明取代旧上下文，初始指令也明确授权这种更新 | 续步、跨轮、修改规则、模式切换、重开会话和压缩后的规则更新回归 |
| 完整重放 | 深拷贝完整输出项，保留 `phase`、`id`、`status` 和未知输出类型；没有可重放密文或提供方签名的推理仍不回传 | 原输出与下一请求、存档和重开后的逐项相等检查；不为旧记录猜填字段 |
| Cache Write | 读取 Responses 的 `input_tokens_details.cache_write_tokens`，普通输入扣除读与写；总量持久化完整分类，重开不再次记整段会话；旧存档仅在完整每模型计数与其他分类一致时补回缺失写入 | 实际 `AppCore → 存档／缓存 → 新引擎重启 → 再次发送` 路径；新旧两种存档都核对四类计数 |
| 请求记录 | 会话最近 128 条请求只保存哈希、计数、耗时、失败标记和白名单诊断原因；摘要请求另标记 | 隐私哨兵、截断边界、主请求／摘要记录；官方诊断的 `type`、可复用／错失 token 数 |
| MCP 声明 | 已知 schema 和服务器指令不随临时断线消失；共享记忆未就绪时保留本地静态声明，失败提示且有界重启 | 启动失败、断线、迟到初始化和声明稳定性回归 |
| 摘要请求 | Responses 历史放得下时使用原指令、工具、历史和运行中档位，在末尾要求摘要并设 `tool_choice: none`；否则保留旧分块路径 | 前缀相等、预算边界、禁止实际执行工具、分块回退、规则与日志视图一致性 |

本地前缀相等不等于实际缓存命中：服务端隐式断点、模型与推理配置、有效寿命、路由和输入变换仍会影响结果。没有启用未经套餐路线探针核对的 `configuration_update`、显式断点、TTL、`reasoning.context`、`comparison_response_id` 或服务端压缩参数；有官方诊断返回时才按白名单记录，不能把缺失诊断解释成命中。

## 原审计逐项结果

| 原编号 | 结果 |
| --- | --- |
| S1、S2 | PowerShell provider 语法不再误入普通文件的只读免批；FileSystem 限定路径规范化后参与受保护路径检查，覆盖目录联接的回归。权限策略仍不是操作系统沙箱 |
| T1 | 文件页上限缩到 48K 字符；循环需要再裁时只留连续行并给出下一 `offset`，不再拼接首尾后声称已经读到末尾 |
| A1、A2 | 已知现代 Claude 使用 adaptive 与原生 effort；旧版／兼容模型保留 manual budget；空文字但带签名的推理原样保留并回传。直连、InvokeModel、Converse 共用相关协议逻辑 |
| L1、O1 的超时 | 连接与读取超时拆开；Responses／Anthropic 已确认开始后，传输中断不盲目重发；HTTP 已响应后的读取失败不再视作未连接。Chat／Converse 的 EOF 与损坏帧同样按非重试错误收束 |
| U1、P1a | Cache Write 账本、追加式上下文和逐请求记录见上表；推理档位或模型真正变化仍可能丢缓存，不把这种代价藏起来 |
| T2 | 默认仓库级 `grep`／`glob` 用安全检查后的 Git tracked＋非 ignored untracked 清单；跟踪但被 ignore 的文件保留。写明默认根目录 `.` 不会退出忽略规则；明确点名的子目录／路径仍能搜索。非仓库和不能安全读取 Git 元数据时回退，不自动运行可疑 Git 扩展；超时说明不武断归咎于正则 |
| L2 | 最多 4 个已放行且无相关扩展钩子的文件只读调用并发，结果按调用顺序提交，停止补齐配对。没有启用 Hook 的 Connections 对象不阻止并发；shell、MCP、写操作与带工具钩子的调用仍串行 |
| C2 | 清单及创建／编辑参数不再在渲染摘要前截成 500 字符，超块预算时完整分块；保留计划中间步骤和编辑中间约束 |
| L3 | 流中断／取消时保存已完成项和可见部分文字；完成的工具调用补结果未知，不重新执行 |
| M1、M2 | 死亡／启动失败有提示，已知声明保留；工具列表翻页、取消通知、结构化结果与非文字结果提示；stderr 有界保留在内存，不进入提示或存档 |
| T3、T4 | 普通文本读／搜／改支持 GB18030；覆盖已有文件须先读且内容未变，保留编码、BOM、换行；成功写入更新读取指纹。原提交屏障和取消回归继续保留 |
| L4、V1 | 无可见回答且无工具时只尝试一次明确恢复，再空则结束为不完整；未知参数给错误，整数字符串可转为整数 |
| O1 的 401 | 尚未收到响应事件时，同一账号对被拒 token 强制刷新并重试一次；已经开始的响应不走这条重试路径 |

## 正式复审中新确认的问题

实现并完成第一轮全量验证后，由主会话做一次正式、缺陷优先的复审，不只沿原报告找答案。追加检查了初始化失败、认证恢复、提供方探测和摘要所有权等边界。

| 问题 | 修复与验证 |
| --- | --- |
| 新回合尚未追加用户项就失败，可能回滚上一轮的单条记录 | 发送／手动压缩先建立新边界，回滚与状态更新只作用于同边界且未结束的记录；已结束和未结束两种旧记录均有回归 |
| 隐式遍历可能跟文件链接或匹配到的目录联接越出批准根目录 | 隐式搜索先检查链接元数据，不读取目标；通配符之后才出现的字面目录也不能绕过。显式路径仍由原权限层批准后读取；真实目录联接与不依赖系统权限的文件链接元数据用例已覆盖 |
| Provider 连接测试自动跟随重定向并转发认证头，且结果与实际推理传输不一致 | 默认探测器和推理传输一样拒绝重定向；双 loopback 服务同时覆盖 `Authorization` 与 `x-api-key`，目标没有收到请求 |
| 直连 Anthropic 路由漏传显式 `enableThinking` 预算 | 路由携带该配置，适配器按模型转换为相应原生思考设置 |
| Claude 家族和 effort 能力边界不完整 | 补 Mythos 与 Preview 的识别；不支持的 minimal／xhigh 在本地明确拒绝，不悄悄改成 high 或 max；已支持的 effort 原样发送 |
| 内部请求构造丢了 Off，使提供方默认 thinking 可能重新生效 | API 内部元数据保留显式关闭意图，Responses 发送边界移除此内部字段；不能完全关闭 thinking 的已知模型本地报错并提示 low，不假装已经关闭，不发送必然无效的请求 |
| 摘要前缀把运行中空档位错误回退成下一轮的新档位 | 与主请求一样用运行中快照，明确保留空值 |
| 停止后遗留摘要可能把用量算给下一轮并覆盖其工作状态 | 用量、请求记录及 finally 的显示更新都验证 owner；模拟旧摘要迟到时新轮账本和工具执行状态不变 |

收尾核对适配器一致性时，还用真实解析器重现了 Chat 的 role-only EOF、Converse 的 start-only EOF／半帧／校验失败／非法帧长会重发的问题；只把这些本地解析错误标为非重试，显式限流／忙碌与连接建立前失败仍保留原重试策略。

- 首轮全量发现 14 个旧契约／测试底座失败，分别更新为追加式上下文、覆盖前先读和显式拒绝刷新等前提；没有删除原取消、原子写、Plan 拒绝或恢复断言。

## 尚未实施或未验证

1. **真实收益与产品路线**：真实 GPT 同模型前后 A/B、套餐对新缓存参数的接受情况、Devin 内部缓存策略，以及真实 Claude／网关／Bedrock 对请求的接受情况均未验证。先取得明确的真实调用上限，再做探针；本轮不动真实账号数据。
2. **价格策略 C1**：没有把 272K 硬编码为所有提供方的自动压缩线。现有用户可设窗口阈值保留；提前压缩可能破坏已热前缀并增加摘要成本，套餐折算和提供方价格也没有共同合同。需要独立的“按成本压缩”策略，不把它冒充缓存命中修复。
3. **能力项 T5／G1／O1 其余**：后台命令、长输出落盘与可恢复预览、联网工具、多处编辑、Goal 总预算、非连续循环检测、图片重传优化未在本轮新增；外部 Connections 能力沿用另一批已合入的实现。
4. **保守回退**：不能安全读取 Git 元数据时，搜索仍回退原文件遍历，可能继续较慢；显式路径可覆盖默认忽略范围。缓存诊断是局部证据，不保证完整解释服务端全部变换。旧记录没有完整每模型用量或协议字段时不猜恢复。
5. **范围**：复审不是全仓库安全认证，外部 CLI、真实登录、真实网络授权与完整发布包没有在本任务重新实测。
