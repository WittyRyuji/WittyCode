# 公开技能来源与兼容边界

WittyCode 的「插件 → 技能商店」目前内置 **OpenAI、Anthropic** 两个公开目录，按固定 Git 提交预览并确认安装；不是登录其他产品后读取其账号内的商店。本轮不新增第三方市场接入。

## 可浏览的公开来源

| 来源 | 内容与当前接入方式 |
| --- | --- |
| [OpenAI Skills](https://github.com/openai/skills) | 内置读取 `skills/.curated`；其他目录不是当前商店目录的一部分。 |
| [Anthropic Skills](https://github.com/anthropics/skills) | 内置读取 `skills` 下的技能。注意逐项许可，不假定所有技能共用同一个许可。 |
| [Vercel Agent Skills](https://github.com/vercel-labs/agent-skills) | Vercel 的公开技能集合；本应用没有内置其远程目录，可下载选定版本后预览本地 `SKILL.md` 导入。 |
| [ClawHub](https://clawhub.ai) / [源码](https://github.com/openclaw/clawhub) | 面向 OpenClaw 的技能与插件注册表，包含社区发布内容；本应用尚未接入搜索或直接安装，不能把 ClawHub 的宿主能力当作已支持。 |
| [skills.sh](https://skills.sh) | 可发现不同 GitHub 仓库技能的目录；不是本应用已接入的安装源。 |

## 在 WittyCode 使用其他来源

1. 选择具体版本或 Git 提交，确认作者、来源和许可；公开可下载不等于有权任意使用。
2. 检查 `SKILL.md` 及随附的 `scripts/`、`references/`、`assets/`，把需要的目录保存到本地。不必运行第三方安装器。
3. 在「插件」选好作用范围，粘贴 `SKILL.md` 或受支持的插件目录，先预览，再确认导入并启用。不要仅复制技能正文而丢掉相对路径依赖。
4. 启用后在会话技能列表中核对；仍需按实际任务验证宿主工具和依赖是否可用。

能识别 `SKILL.md` **不等于兼容该技能的全部运行环境**。例如 ClawHub 技能可能依赖 OpenClaw 的消息、定时任务、浏览器、子代理或专属工具，或声明额外的二进制、环境变量与操作系统条件；这些不会因为导入成功就由 WittyCode 自动提供。此类技能需要适配或不能使用，不能承诺全部直接兼容。

预览与安装不执行技能脚本，但技能实际被调用后，代理可能按其说明运行命令；仍需来源审查和正常权限控制。不要从不可信说明中复制凭据或执行所谓“一键修复”。

## 图标

技能商店的卡片和安装预览使用随应用打包的用途分类图标，覆盖文档、表格、设计、图片、浏览器、音频和代码；无法识别用途时显示通用技能图标。它们不是伪装成原仓库提供的品牌标识，也不会额外从第三方下载远程图像。
