The first public alpha of WittyCode, a coding-agent desktop app for Windows with its own agent loop.

**Download** `WittyCode-0.1.0a1-win-x64.zip`, check it against `WittyCode-0.1.0a1-win-x64.zip.sha256` (`Get-FileHash -Algorithm SHA256`), unzip it and run `WittyCode.exe`. Python and every dependency are inside; nothing is installed. The build provenance can be checked with `gh attestation verify <zip> --repo WittyRyuji/WittyCode`.

**What is in it**

- WittyCode's own agent loop, with your ChatGPT plan ("Sign in with ChatGPT") or your own API providers (OpenAI, Anthropic, OpenAI-compatible endpoints, AWS Bedrock); Devin as an optional engine.
- File, search and shell tools behind three permission levels; approvals and questions as cards; queue or steer messages while a turn runs; `/compact`, `/plan`, `/goal`; skills and custom commands.
- Shared local memory for every engine, importing from other apps; the file panel for Markdown, PDF and pictures.

**Before you use it**

- Alpha: expect rough edges. Windows 10/11 x64 only; the interface is in Chinese for now.
- **The agent loop has no OS sandbox yet.** In a repository you do not trust use the ask level, never full access.
- Not code-signed: SmartScreen may say "unknown publisher".
- Bedrock has not completed a real request against an AWS account yet.
- No telemetry; data stays in `%APPDATA%\WittyCode\`.

What comes next: [ROADMAP.md](https://github.com/WittyRyuji/WittyCode/blob/main/ROADMAP.md).

WittyCode 的首个公开 alpha 版本：Windows 上的编程代理桌面应用，自带代理循环。

**下载** `WittyCode-0.1.0a1-win-x64.zip`，用 `WittyCode-0.1.0a1-win-x64.zip.sha256` 核对（`Get-FileHash -Algorithm SHA256`），解压后运行 `WittyCode.exe`。包里带 Python 和全部依赖，不安装任何东西。构建来源可以用 `gh attestation verify <zip> --repo WittyRyuji/WittyCode` 核对。

**使用前请知道**

- Alpha 版本，会有粗糙的地方。只支持 Windows 10/11 x64，界面暂时是中文。
- **代理循环还没有系统级沙箱**。在不信任的仓库里用「询问」档，别用「完全访问」。
- 没有代码签名：SmartScreen 可能提示「未知发布者」。
- Bedrock 还没有在真实 AWS 账号上跑通过。
- 没有遥测，数据在 `%APPDATA%\WittyCode\`。
