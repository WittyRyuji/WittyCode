The first public beta of WittyCode, a coding-agent desktop app for Windows with its own agent loop and a coordinated agent team (Fusion).

**Download** `WittyCode-0.3.0b1-win-x64.zip`, check it against `WittyCode-0.3.0b1-win-x64.zip.sha256` (`Get-FileHash -Algorithm SHA256`), unzip it and run `WittyCode.exe`. Python and every dependency are inside; nothing is installed. The build provenance can be checked with `gh attestation verify <zip> --repo WittyRyuji/WittyCode`.

**What is in it**

- WittyHarness, WittyCode's own agent loop: file, search and shell tools behind three permission levels, approvals and questions as cards, queued and steering messages, plan mode, `/compact`, `/goal`, skills and custom commands. Use it with your ChatGPT plan ("Sign in with ChatGPT") or your own API providers (OpenAI, Anthropic, OpenAI-compatible endpoints, AWS Bedrock); Devin and Factory CLI accounts are optional engines.
- **Fusion**: a main agent coordinates Coders, a Runner and a QualitySampler on the same project. The Agents Team panel shows a live task graph with each agent's brief, evidence and token usage, and Fusion Drive keeps the project map local.
- In-conversation file preview: source code with line references, Markdown, PDF, images and animated GIFs, MP4/WebM video, and `.docx`/`.xlsx`/`.pptx`. Attach by paste, drop or picker.
- Local project memory shared across engines, conversation import from other apps, stdio and Streamable HTTP MCP servers, skills, plugins and hooks managed in Settings, per-project rules and defaults.

**Before you use it**

- Beta: expect rough edges. Windows 10/11 x64 only; the interface is in Chinese for now.
- **The agent loop has no OS sandbox yet.** In a repository you do not trust, use the ask level, never full access.
- Not code-signed: SmartScreen may say "unknown publisher".
- GitHub and Google connectors are unavailable in this build: the publisher's OAuth client IDs are not registered yet.
- Bedrock and Factory have not completed a real end-to-end request yet.
- No telemetry; data stays in `%APPDATA%\WittyCode\`.

WittyCode 的首个公开 beta：Windows 上的编程代理桌面应用，自带代理循环，也有主代理带队的 Fusion 模式。

**下载** `WittyCode-0.3.0b1-win-x64.zip`，用 `WittyCode-0.3.0b1-win-x64.zip.sha256` 核对（`Get-FileHash -Algorithm SHA256`），解压后运行 `WittyCode.exe`。包里带 Python 和全部依赖，不安装任何东西。构建来源可以用 `gh attestation verify <zip> --repo WittyRyuji/WittyCode` 核对。

**里面有什么**

- WittyHarness 自有循环：文件、搜索、命令行工具分三档权限，批准和提问是卡片，可排队、可插话，有计划模式、`/compact`、`/goal`、技能和自定义命令。登录你的 ChatGPT 套餐（「Sign in with ChatGPT」），或用自己的 API Provider（OpenAI、Anthropic、OpenAI 兼容端点、AWS Bedrock）；Devin、Factory 账号是可选引擎。
- **Fusion**：主代理带着 Coder、Runner、QualitySampler 在同一个项目上分工；Agents Team 面板实时显示任务图和每个代理的简报、证据、token 用量；Fusion Drive 把项目地图存在本地。
- 对话内直接预览文件：带行号引用的源码、Markdown、PDF、图片和 GIF 动图、MP4/WebM 视频、`.docx`/`.xlsx`/`.pptx`；粘贴、拖入或选择文件做附件。
- 跨引擎共享的本地项目记忆、从其他应用导入会话、stdio 和 Streamable HTTP MCP 服务器、设置里管理的技能/插件/钩子、项目级规则和默认值。

**使用前请知道**

- Beta 版本，会有粗糙的地方。只支持 Windows 10/11 x64，界面暂时是中文。
- **代理循环还没有系统级沙箱**。在不信任的仓库里用「询问」档，别用「完全访问」。
- 没有代码签名：SmartScreen 可能提示「未知发布者」。
- 本构建里 GitHub / Google 连接器不可用：发布方的 OAuth 客户端还没注册。
- Bedrock 和 Factory 还没在真实账号上端到端跑通过。
- 没有遥测，数据在 `%APPDATA%\WittyCode\`。
