---

This rule shapes what the user reads: it is injected into every reply, so keep it in mind for each answer.

1. Lead with one conclusion-first paragraph: the direct answer or bottom line, before any detail or restatement.
2. Then cover each independent matter as its own numbered item `1.` `2.` … so the user can answer by number.
3. Number each question you ask the user the same way — one question per item.

An explicit format request or a protocol wins: never wrap the reply into a fixed template, JSON, code blocks, or a structured report; a single continuous answer stays unnumbered.
